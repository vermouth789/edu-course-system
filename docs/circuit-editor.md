# Circuit Editor Design

## 功能定位

面向电路电子课程，学生端增加一个：

`电路图绘制与提交模块`

它的目标不是普通自由画板，而是让学生基于标准电路元件进行绘制、保存、下载和提交。

## 使用场景

### 学生场景

- 按实验要求绘制电路图
- 完成课后作业中的电路设计题
- 在章节学习中跟随老师示例搭建基础电路
- 下载绘制结果用于实验报告或提交作业

### 教师场景

- 发布需要绘制电路图的作业
- 查看学生提交的电路图预览
- 打开学生提交的电路图继续检查
- 后续接入 AI 识别电路结构和辅助评分

## 为什么不做普通画板

普通画板的问题：

- 元件图形不标准
- 连线无法吸附到元件引脚
- 后续难以识别“这是什么元件”
- 不利于 AI 判断串联、并联和连接正确性

因此更适合的设计是：

`元件节点化 + 引脚连线 + 图结构保存`

## 推荐正式版技术路线

正式版建议采用：

- 前端：`Next.js`
- 编辑器：`React Flow`
- 预览/导出：`html-to-image`
- 自定义符号：`SVG 自定义节点`

参考官方文档：

- [React Flow Overview](https://reactflow.dev/)
- [Custom Nodes](https://reactflow.dev/learn/customization/custom-nodes)
- [Handles](https://reactflow.dev/learn/customization/handles)
- [Save and Restore](https://reactflow.dev/examples/interaction/save-and-restore)
- [html-to-image](https://github.com/bubkoo/html-to-image#readme)

## 为什么推荐 React Flow

因为电路图天然符合：

- 元件 = 节点
- 引脚 = 连接点
- 导线 = 边

这样后续会更容易实现：

- 元件拖拽
- 引脚吸附连线
- 图结构保存
- 重新编辑
- AI 识别电路拓扑结构

## 当前 Demo 的实现策略

当前静态 demo 不直接引入 `React Flow`，先使用：

`原生 SVG + 轻量交互脚本`

先展示核心体验：

- 选择元件并放置

- IEC 风格常用元件符号子集

- 下载 `SVG`

这样不依赖构建工具，便于当前仓库快速演示。

## IEC 标准说明

电路图符号建议对齐：

- `IEC 60617` 图形符号体系

说明：

- IEC 60617 官方完整符号数据库为标准资源库，正式商用需按授权使用
- 正式版建议采用“标准库作为来源，本地元件库作为运行时能力”的方案
- 当前 demo 只演示常用元件的 IEC 风格子集
- 正式版再扩展为更完整的元件符号库与属性库

参考：

- [IEC 60617 Database](https://library.iec.ch/iec60617)
- [IEC Webstore Entry](https://webstore.iec.ch/en/publication/2723)

## 推荐接入方案

建议采用：

`IEC 60617 标准来源 + 本地结构化元件库`

即：

1. 学校或项目方获得 IEC 60617 的授权访问
2. 根据授权内容整理出课程所需的常用元件集合
3. 在系统内部建立自己的元件数据模型
4. 前端编辑器只消费我们自己的元件库，不直接依赖外部数据库

这样做的好处：

- 符合标准来源要求
- 前端编辑器性能和离线能力更稳定
- 更容易绑定端子、属性和连通性检查规则
- 更适合后续 AI 识别与作业评分

## 线材与接口

正式版电路图数据不只保存“线”，还应保存线材和接口信息：

- 线材类型：电源线、信号线、接地线、屏蔽线
- 线径规格：如 `0.5mm²`、`0.75mm²`
- 接口接茬：端子压接、插接件、焊接接茬、临时绞接
- 颜色规范：电源、信号、接地应在画布中明确区分

这些信息后续可用于：

- 工程报告生成
- 连通性与规范检查
- 教师评阅
- AI 辅助诊断

## 连通性检查

电路图编辑器后续不仅要能画，还要能做基础校验。

第一阶段建议支持：

- 是否存在从电源正极到负极的闭合路径
- 是否存在悬空端子
- 是否存在未接入网络的孤立元件

后续再扩展：

- 串并联结构识别
- 极性检查
- 开关状态检查
- 与标准答案对比

### diagram_json 建议结构

```json
{
  "version": "1.0",
  "components": [
    {
      "id": "resistor-1",
      "type": "resistor",
      "x": 220,
      "y": 160,
      "rotation": 0,
      "label": "R1"
    }
  ],
  "connections": [
    {
      "id": "wire-1",
      "from": "source-1:right",
      "to": "resistor-1:left"
    }
  ]
}
```

## 下载与导出

建议同时保留两种导出格式：

### 1. SVG

优点：

- 清晰不失真
- 适合打印和后续继续编辑
- 更适合电路图这类符号化图形

### 2. PNG

优点：

- 学生交作业方便
- 老师预览方便
- 可直接插入 Word 或实验报告

## 与 AI 老师的结合方式

这个功能后续可以和老师 Agent 联动：

- AI 老师根据当前章节给出电路绘制练习
- 学生绘图完成后提交到作业模块
- AI 识别电路结构并检查基本连接逻辑
- AI 给出反馈，例如“电源与电阻未闭合”“接地位置不合理”
