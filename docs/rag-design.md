# RAG Design

## 为什么选双层切片

你的系统不只是问答，还要做：

- 当前章节随机出题
- 主观题 AI 评分
- 课程私有知识库答疑
- 薄弱点分析与推荐

如果只做单层切片，通常会出现两个问题：

1. 召回够准，但上下文不足
2. 上下文够多，但命中不够精确

所以这里建议用双层切片。

## 切片设计

### 粗粒度切片

目标：保留教学上下文。

建议单位：

- 一节课摘要
- 一个小节摘要
- 一个实验说明摘要

建议字段：

- `course_id`
- `chapter_id`
- `section_id`
- `chunk_type=coarse`
- `title`
- `summary`
- `keywords`

### 细粒度切片

目标：提高检索与出题精度。

建议单位：

- 概念定义
- 公式与定理
- 解题步骤
- 例题讲解
- 注意事项
- 常见错误

建议字段：

- `course_id`
- `chapter_id`
- `section_id`
- `chunk_type=fine`
- `knowledge_point`
- `content`
- `source_page`
- `content_kind`

## 检索流程

1. 先按课程过滤
2. 再按章节或知识点做精准过滤
3. 再做向量检索召回细粒度切片
4. 回查命中切片对应的粗粒度摘要
5. 重排后交给大模型生成答案或题目

## 题目生成建议

当前章节随机出题不要直接从大模型裸生成，建议：

1. 先定位章节
2. 召回当前章节细粒度切片
3. 结合题型模板生成题目
4. 用课程术语和教师风格做二次约束

## AI 评分建议

主观题评分建议采用双轨：

1. `rubric` 规则提取
2. `RAG` 证据校验

这样评分会更稳，也方便教师复核。
