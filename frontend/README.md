# EduSpark Frontend

正式前端入口。当前阶段先用零依赖页面跑通三端功能边界和后端接口，后续再迁移为 `Next.js`。

## 启动

```bash
python3 -m http.server 5173 --directory frontend
```

打开：

```text
http://127.0.0.1:5173/
```

## 三端功能

- 学生端：课程学习、AI 教师问答、章节随机出题、AI 评分、工程报告提交。
- 教师端：学生管理、学生画像、班级学情、工程报告评阅。
- 管理员端：权限控制、RAG 参数调节、系统健康检查。

## 后端接口

默认连接：

```text
http://127.0.0.1:8000
```
